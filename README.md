# 🎯 GIF Riddle – Random GIF Generator

GIF Riddle is a fun React-based web application that generates random GIFs or tag-based GIFs using the **GIPHY API**.
Users can explore random GIFs or search GIFs based on custom tags.

---

## 🚀 Live Demo

🔗 https://gif-riddle.vercel.app/

---

## ✨ Features

* 🎲 Generate random GIFs instantly
* 🔎 Search GIFs using custom tags
* ⚡ Custom React Hook for API handling
* 🔄 Dynamic loading spinner
* 📱 Responsive UI with Tailwind CSS
* 🌐 Deployed using Vercel

---

## 🧰 Tech Stack

* **Frontend:** React.js
* **Styling:** Tailwind CSS
* **API:** GIPHY Developer API
* **HTTP Client:** Axios
* **Hooks:** Custom React Hook (`useGif`)
* **Deployment:** Vercel
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

Clone repository:

```
git clone https://github.com/ankushkumarcity960/gif-riddle.git
```

Move into project:

```
cd gif-riddle
```

Install dependencies:

```
npm install
```

Create `.env` file:

```
REACT_APP_GIPHY_API_KEY=your_api_key
```

Run locally:

```
npm start
```
